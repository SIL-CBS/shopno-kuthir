# স্বপ্ন কুঠির — হিসাব অ্যাপ v2 (Shopno Kuthir Accounts v2)

নতুন ভার্সন: tree মেনু, আসল ডেটা, বাংলা/English, প্রতিটা রিপোর্টে ফিল্টার ও Excel/PDF।
পুরনো সাইট `/v1`-এ আগের মতোই আছে। এই ভার্সন `/v2`-এ।

## ডেটা কোথায় থাকে

1. **অ্যাপের ভেতরে বসানো আসল ডেটা** (আগস্ট–নভেম্বর ২০২৬, `base`)। এটা বদলাতে হলে অ্যাপ নতুন করে বানিয়ে প্রকাশ করতে হয়। মাসিক কাজে Claude এটা করে।
2. **Google Sheet "Shopno Kuthir DB"** (Drive › Sopno Kuthir ফোল্ডার):
   - `Entries` ট্যাব: অ্যাপ থেকে বা Claude-এর দেওয়া নতুন এন্ট্রি। অ্যাপ এটাই পড়ে।
   - `Base_Expenses`, `Base_Deposits`, `Base_Months`, `Base_Members`: বর্তমান আসল ডেটার কপি, শুধু দেখার জন্য। এখানে বদলালে অ্যাপ বদলায় না।
   - `Keys`: তিনটা গোপন কী। এই ট্যাব কারো সাথে শেয়ার করবেন না।
3. **Apps Script** (শিটের সাথে বাঁধা, `Code.gs`): শিট ও অ্যাপের মাঝের ছোট API।

## এন্ট্রি দুই পথে

1. **ছবি থেকে:** Sohel খাতা/ব্যাংকের ছবি Claude-কে দেন। Claude পড়ে অংক দেখিয়ে নিশ্চিত করে, তারপর শিটের `Entries` ট্যাবে তোলে।
2. **অ্যাপ থেকে:** এডমিন বা ম্যানেজার হিসেবে এন্ট্রি ফর্ম (এন্ট্রি মেনু)।

### ভূমিকা

| ভূমিকা | কী পারে |
|---|---|
| admin | সব। নিজের এন্ট্রি সাথে সাথে হিসাবে আসে। ম্যানেজারের এন্ট্রি অনুমোদন করে, মোছে |
| manager | এন্ট্রি দিতে পারে, মুছতে পারে না। এন্ট্রি "অনুমোদনের অপেক্ষায়" থাকে, এডমিন অনুমোদন করলে হিসাবে আসে |
| viewer | শুধু দেখে |

কী বসানোর জায়গা: অ্যাপের **সেটিংস › ডেটাবেস সংযোগ**। কী ব্রাউজারে মনে থাকে, "বিচ্ছিন্ন করুন" চাপলে মুছে যায়।

## এন্ট্রির সময়ের যাচাই

ক্রমিক নম্বর নিজে বসে ও ডুপ্লিকেট আটকায়; একই দিনে একই বিবরণ ও টাকা সতর্কতা; খাতের গড়ের ৩ গুণের বেশি হলে সতর্কতা; ব্যাংক এন্ট্রিতে খাতায় লেখা স্থিতি মেলানো; জমার মাস (১০ তারিখ পর্যন্ত হলে আগের মাস প্রস্তাব)।

## হিসাবের নিয়ম

- সার্ভিস চার্জ ৬% (০৬/০৮/২০২৬ থেকে), প্রতি মাসের খরচের উপর, প্রদেয়।
- ট্রায়াল ব্যালেন্স: ডেবিট = খরচ + অন্যান্য পরিশোধ + সার্ভিস চার্জ + ব্যাংক স্থিতি; ক্রেডিট = জমা + প্রদেয় সার্ভিস চার্জ।
- ব্যাংক স্থিতি = শুরু + জমা − খরচ − অন্যান্য পরিশোধ ± ব্যাংক এন্ট্রি।
- বকেয়া: ছাদের বকেয়ায় মাসিক ১০% চক্রবৃদ্ধি (০১/০৯/২০২৬ থেকে), জমা আগে ছাদে তারপর কিস্তিতে। অ্যাপ এই হিসাব নিজে করে না, আগের পদ্ধতির ফল দেখায়। নতুন জমা শুধু সরল সমন্বয়ে বসে।
- কিস্তি: বড় (১/৩) ১,৩০,০০০; ১/৪ শেয়ারে ১,০০,০০০; ১/৮ শেয়ারে ৫০,০০০।

## জানা সীমা

- সেপ্টেম্বরে জমার তালিকা ১১,২৮,০০০ বনাম ব্যাংকভিত্তিক ১০,৭৮,০০০: ৫০,০০০-এর পার্থক্য "জমা সমন্বয়" সারিতে আলাদা দেখানো।
- নভেম্বরে ব্যাংক খাতা ও হিসাবমতো স্থিতিতে গরমিল ৬৫,১৬৭।
- শিটে সংরক্ষণ শুধু GitHub-এর লক করা `/v2` পাতায় চলে। claude.ai-এর কপিতে ব্রাউজারের নিয়মে শিটে লেখা যায় না।
- বাদ বা বাকি (ক্রস চেক পাতায় বিস্তারিত): বাজেট বনাম খরচ, পূর্বাভাস, চুক্তিপত্র ও বিশ্লেষণ পাতা, সার্চ, Banglish → বাংলা।

## প্রকাশ ও লক

- GitHub: `SIL-CBS/shopno-kuthir` রিপো পাবলিক, তাই `/v2/index.html` AES-256-GCM (PBKDF2-SHA256, ২,৫০,০০০ ধাপ) দিয়ে এনক্রিপ্ট করা। পাসওয়ার্ড দিলে পাতা খোলে।
- claude.ai: একই অ্যাপ প্রাইভেট আর্টিফ্যাক্ট হিসেবে (শুধু Sohel দেখে)।
- মূল সাইট (root) ও `/v1` অপরিবর্তিত।

## মাসিক কাজের ধারা

1. ছবি Claude-কে দিন (খাতা, ব্যাংক জমা খাতা, কমিটির তালিকা)।
2. Claude পড়ে অংক দেখায়, আপনি নিশ্চিত করেন।
3. Claude শিটে তোলে, বা আপনি নিজে অ্যাপে এন্ট্রি দেন (এডমিন/ম্যানেজার)।
4. মাস শেষে Claude আসল ডেটা অ্যাপে বসিয়ে `/v2` নতুন করে প্রকাশ করে ও PDF/Excel রিপোর্ট Drive-এ রাখে।

## সেটআপ (একবারের কাজ)

1. শিটে Extensions › Apps Script খুলে `Code.gs` বসান, সেভ করুন।
2. `setup` ফাংশন একবার চালান। `Keys` ট্যাবে ৩টা কী আসবে।
3. Deploy › New deployment › Web app (Execute as: Me, Access: Anyone)। যে URL আসবে সেটা অ্যাপে বসানো হয়।
4. কোড বদলালে: Deploy › Manage deployments › Edit › New version।
