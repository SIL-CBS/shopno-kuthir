update করার নিয়ম

লেখা বা নকশা বদলালে শুধু ওয়েব ফাইল push করলেই ওয়েব আর APK দুটোতেই চলে যায়। APK নতুন করে লাগে শুধু অ্যাপের নিজস্ব (native) অংশ বদলালে।

প্রতিবার সংস্করণ বাড়ানো

  1. app.js: APPVER আর APPDATE বাড়ান, CHANGES-এর শুরুতে নতুন সারি দিন
  2. sw.js: ক্যাশ নাম munajat-vNN আর ?v=NN
  3. index.html: data.js?v=NN আর app.js?v=NN
  4. node --check munajat/app.js, তারপর commit ও push
  5. GitHub Pages ১–২ মিনিটে ছাপে; অ্যাপ খুললে নিজে নতুনটা নেয় (service worker updateViaCache:'none' + reload)

APK নতুন করে লাগে যখন

  • নতুন native plugin যোগ হলে (munajat-v2/package.json)
  • আইকন, শুরুর পর্দা, অনুমতি (AndroidManifest), MainActivity বদলালে
  • তখন capacitor.config.json-এ appendUserAgent: "MunajatApk/N" আর build.gradle-এ versionCode বাড়ান, app.js-এ APK_LATEST = N দিন
  • অ্যাপের ভেতরে "নতুন APK" বোতাম নিজে দেখায়
APK একটা স্থায়ী পরীক্ষামূলক চাবি দিয়ে সই করা (munajat-v2/android/app/munajat-test.keystore, বিল্ড ৩ থেকে)। চাবি বদলালে পুরোনো অ্যাপ Uninstall করে বসাতে হবে, তাই এটা বদলাবেন না। Play Store-এ দেওয়ার সময় আলাদা release চাবি লাগবে।
